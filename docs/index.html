Earnings Call Tracker

Guidance, results and management tone from the latest earnings calls · every figure checked against the source
How it works: Claude reads each company’s latest call transcript and press release and returns structured items. Each item must quote its source word for word. Python code then checks every quote against the source text and every number against its quote, and any item that fails is left out and listed in that company's audit log. New calls are picked up automatically every day. Built by Sabina Islamova · source code.
Owner settings

Live analysis starts a GitHub Action in this repo, so it needs a GitHub access token that's allowed to run it. The token is stored only in this browser (never in the site or the repo). Create a fine-grained token at github.com → Settings → Developer settings → Personal access tokens, limited to the earnings-tracker repo, with Actions: Read and write and Contents: Read-only.
